About This Project

Welcome! This web application converts sign language videos into phonetic sign notation (HamNoSys) and displays a 3D animated avatar performing the sign. It helps bridge the communication gap by showing how sign language videos can be converted into animated avatars for easy visual understanding.

Future Development

Universal Any-to-Any Sign Language Converter

Our goal for future development is to build a universal sign-language-to-sign-language converter. In the future, this system will take a video in any sign language and automatically translate and convert it into any sign language requested by the user, making global communication barrier-free.

Any Input Sign Language

Recognizing gestures from video clips in any regional or national sign language.

Universal Phonetic Translation

Translating signs into universal phonetic notation for cross-lingual conversion.

Requested Output Avatar

Rendering the translated signs using 3D animated avatars in whichever sign language the user requests.
